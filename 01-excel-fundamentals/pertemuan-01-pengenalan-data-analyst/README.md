# Pertemuan 01 - Pengenalan Data Analyst

## Deskripsi
Pada pertemuan ini saya mempelajari dasar-dasar Data Analyst menggunakan Microsoft Excel dengan studi kasus penjualan toko elektronik TechStore.

## Tujuan Pembelajaran
- Mengenal dataset dan struktur data.
- Memahami penggunaan rumus dasar Excel.
- Melakukan analisis pendapatan.
- Menggunakan fungsi IF untuk klasifikasi transaksi.

## Tools
- Microsoft Excel

## Materi yang Dipelajari
- SUM
- AVERAGE
- MAX
- MIN
- COUNT
- IF

## Hasil Analisis
- Total pendapatan: Rp7.250.000
- Rata-rata transaksi: Rp906.250
- Pendapatan tertinggi: Rp3.000.000
- Produk terlaris berdasarkan unit: Mouse
- Produk dengan pendapatan terbesar: Monitor

## Kesimpulan
Produk dengan jumlah unit terjual terbanyak belum tentu menjadi produk dengan pendapatan terbesar.
